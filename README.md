### Questions: (February 8, 2026)
## Q1.What is the Fashion MNIST dataset?
Ans. Machine learning models for image categorization are trained and tested using public picture datasets.

## Q2.Why do we normalize image pixel values before training?
Ans.Normalization facilitates the model's processing of the input, leading to more effective learning.

## Q3.List the layers used in the neural network and their functions.
Ans.The model prepares the picture using a Flatten layer, learns features using a Dense layer with ReLU, and classifies the image using a Dense layer with Softmax.

## Q4.What does an epoch mean in model training? 
Ans.A complete cycle in which the model trains on every training image once is called an epoch.

## Q5.Compare the predicted label and actual label for the first test image.
Ans.To determine if the model accurately categorized the picture, the predicted label and the actual label are compared.

## Q6.What could be done to improve the model’s accuracy?
Ans.Using a CNN, extending training epochs, and refining the network design can all increase the model's accuracy.
